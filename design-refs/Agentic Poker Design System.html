Phase 2 · extraction

The record, not
a new direction.

The direction is locked. These five sheets exist so the production port can follow it mechanically: every value, every component name, every state combination — components rendered from the same code the screens use, palette swatches bound to the live token constants, and the type scale derived by scanning the rendered document rather than typed out.

Nothing here is a new decision. Where two iterations disagreed, the latest won — and both contradictions I could not resolve without inventing are flagged on the state matrix rather than quietly patched.
