# Railbird bundled fonts

Font binaries are unmodified WOFF2 assets supplied in Agentic Poker (56).zip, inside Railbird Landing Page (standalone).html. manifest.json records the extracted asset IDs and SHA256 checksums. The original embedded copyright notices are retained below. Each family is distributed under SIL Open Font License 1.1; the corresponding full upstream notice accompanies it.

Variable weight ranges come from the binary fvar table. Oswald in this archive supports 400–700; these cover current product usage. Playfair italic is included as authored. Other italic styles keep the browser synthesis already used by the reference.
